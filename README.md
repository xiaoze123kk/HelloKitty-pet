# KittyPet

KittyPet 是一只安静、可互动的 Windows 桌面猫咪。它会陪你工作、休息和度过日常时光，不打扰你的其他应用。

## 主要功能

- 透明无边框桌宠，可自由拖动和缩放
- 点击头部、脸颊、鼻子、胡须、蝴蝶结和配饰，会有不同反馈
- 长按可以撸猫，快速划动鼠标可以逗它扑过来
- Kitty 会眨眼、呼吸、整理自己、打哈欠、睡觉和起床
- 可选的视线跟随、桌面散步和陪伴提醒
- 内置衣柜，可直接试穿帽子、耳机、节日装饰等头部配饰
- 「我们的小窝」记录相处天数、互动、回忆、收藏和每周陪伴记录
- 支持设置 Kitty 对你的称呼、你对 Kitty 的称呼和纪念日

## 安装与启动

双击 `KittyPet_0.12.5_x64-setup.exe` 完成安装，然后从桌面或开始菜单启动 KittyPet。

首次启动时，可以在设置中填写称呼和纪念日；也可以跳过，之后再补充。

## 基本操作

- **拖动**：按住 Kitty 移动即可拖到桌面任意位置
- **点击**：点击不同部位查看不同反应
- **长按**：按住不动，开始撸猫
- **右键**：打开设置
- **缩放**：在设置中调整大小，也可以按住 Ctrl 滚动鼠标滚轮

## 隐私

KittyPet 默认完全离线运行：

- 不联网，不上传数据
- 不读取前台应用、浏览记录或键盘内容
- 称呼、纪念日、互动记录和你主动添加的记忆只保存在本机
- Kitty 不会从聊天或行为中自行推测需要记住的内容

## 小窝与备份

在托盘菜单或设置中打开「我们的小窝」，可以查看今日互动、陪伴记录、记忆、衣柜和收藏。

小窝支持备份与恢复。恢复前会自动保留一份安全副本。

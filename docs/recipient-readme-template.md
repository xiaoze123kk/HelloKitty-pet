# KittyPet 使用说明（给收礼人）

嗨，这是送你的桌面小宠物。

**它是什么**
- 一个住在桌面上的小角色：可以按住它拖到任意位置，点它会回应你。
- 偶尔会主动和你说句话，白天问候、深夜提醒你早点休息。

**它是安全的**
- 完全离线运行：不会上传任何数据，不会读取你的文件、剪贴板、屏幕或浏览器内容。
- 它只在本机保存三样东西：自己的位置、设置、还有和你的互动记录。

**常用操作**
- 按住角色 → 拖到桌面任意位置
- 点一下 / 连续点 → 它会害羞、开心
- 右键角色 → 打开设置
- 右下角托盘图标：
  - 左键：显示 / 隐藏
  - 右键：暂停互动 · 设置 · 退出
- 设置里可以：关闭开机启动、开启勿扰模式、清除所有数据

如果 Windows 弹出 SmartScreen 提示，选"更多信息 → 仍要运行"即可（这是未签名私人小程序的正常现象）。

# KittyPet 使用说明

嗨，这是送你的桌面小宠物——一只住在桌面上的小白猫。

**它会做什么**
- 平时在桌面上呼吸、眨眼，偶尔换换姿势；
- 白天会打招呼、提醒你喝水，坐久了提醒你起来活动，深夜提醒你早点休息；
- 点它、连点它、拖它，它都会回应你；
- 它会自己观察、洗脸、玩耍、找你或休息，重新打开后也会延续自己的状态；
- 相处越久，会解锁更多秘密和纪念物，还会写下今天与最近七天的小记录。

**常用操作**
- 按住它 → 拖到桌面任意位置
- 点一下 / 双击 / 连点 → 它会有不同反应
- 按住 Ctrl 在它身上滚动滚轮 → 缩放大小（50%–200%）
- 右键它 → 打开设置
- 右下角托盘图标：
  - 左键：显示 / 隐藏
  - 右键：显示/隐藏 · 我们的小窝 · 勿扰模式 · 设置 · 退出

**设置里可以做什么**
- 始终置顶：让它一直显示在其它窗口上方
- 勿扰模式：暂时不弹气泡，安安静静待着
- 开机启动：开机时自动出现
- 大小：拖动滑杆或点 +/−（50%–200%）
- 我们的小窝：查看今天、秘密、纪念物和最近七天的陪伴记录
- 清除所有数据：把互动记录和设置恢复成刚安装的状态

**备份关系记录**
- 打开“我们的小窝 → 收藏”，可以创建本地备份或恢复最近一次备份。
- 备份放在“文档/KittyPet Backups”中；恢复前程序还会自动保存当前数据。

**它只在本机保存三样东西**
- 自己的窗口位置、设置、互动记录和本地行为状态。
- 完全离线运行：不会上传任何数据，也不会读取你的文件、剪贴板、屏幕或浏览器内容。

**可能遇到的问题**
- 如果 Windows 弹出 SmartScreen 提示，选“更多信息 → 仍要运行”即可（这是未签名私人小程序的正常现象）。
- 卸载方法：Windows 设置 → 应用 → 已安装的应用 → KittyPet → 卸载。
- 想让它安静一会儿：托盘图标右键 → 勿扰模式。
